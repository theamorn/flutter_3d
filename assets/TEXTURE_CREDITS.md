# Room textures

Photo textures from [Poly Haven](https://polyhaven.com), licensed **CC0** (public domain).
Downscaled and re-encoded for the app (colour maps 1K or 512 px, normal maps 512 px, OpenGL convention).
Fabrics marked *neutral* were converted to grey so the room code can tint them per object.
